    How it works

    Every listing is editable. Run compiles it with the Eclipse compiler and runs it on a Java runtime inside the page (CheerpJ); the first run on a page takes a few seconds while the runtime loads. Visualize steps through the program on Python Tutor.

    Java runs locally in your browser (CheerpJ and the Eclipse Compiler for Java). Nothing you type is sent anywhere. Progress and XP are saved in this browser; the ⋯ menu inside a workbook exports and imports them.
