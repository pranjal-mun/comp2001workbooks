Lecture summary

HelpBot now connects recognised keywords with replies in a HashMap<String, String>. It cleans a question, returns the first matching keyword's reply, and records the keyword in a count map and a topic set. The sequence submit, compile, submit, test gives counts 2, 1, and 1 and three distinct topics. Empty questions keep the same prompt; an unknown nonempty question still receives a random general reply. Matching uses substrings, and multiple matching keys have no promised priority.

The complete class below runs with a supplied demonstration. It checks named lookups, missing keys, repeated topics, ratings, and replacement of a reply. The random fallback is checked by membership in the four-entry general reply list, so its printed output is repeatable without giving the application a fixed seed.

termmeaning
map and type argumentsA map stores key/value entries. In HashMap<K, V>, K is the key type and V is the value type. new HashMap<>() infers the types from the declaration.
lookup and missing keysget(key) returns the value, or null for an absent key in these maps. containsKey checks membership; getOrDefault(key, 0) supplies 0 without inserting an entry. Check for null before calling an instance method on a missing result.
replacement and traversalput replaces an existing key's value without increasing size. A new key adds one entry. keySet() allows key traversal, but HashMap does not promise traversal order.
boxed countsThe count map stores Integers. Reading into an int unboxes a value; storing count + 1 boxes the new value. A repeated keyword raises its count.
set and duplicatesHashSet stores each distinct element at most once. A second addition of submit adds no duplicate. Use contains, add, remove, isEmpty, size, or a for-each loop; there is no indexed get or promised print order.
choosing collectionsUse a list for ordered replies with possible duplicates, a set for distinct topics, and a map for a reply or count per key. General List, Set, and Map declarations describe these roles; their relationship to concrete classes is studied later.
fresh clinic snapshotsCount and name snapshots use all current appointments and exact stored names. Each call builds a separate collection from the schedule list. Cancellation changes the list; an old snapshot remains unchanged and a fresh one reflects cancellation.
static fields and lifetime countsA static field belongs to the class and is shared by its objects. Each constructor increments the creation counter once. Cancellation lowers current schedule membership but not the lifetime creation count. BlueJ keeps class state until the JVM is reset.
final and constantsA final field cannot be reassigned after its permitted initialization. A final reference can still point to a mutable list. static final gives a shared constant, such as DEFAULT_MINUTES = 15. Keep mutable fields private.
class methods and mainCall a static method through the class name. It has no current object or this reference; instance state needs an explicit receiver. ClinicSchedule.java 
import java.util.ArrayList;
import java.util.Random;

public class ClinicSchedule
{
    private ArrayList<Appointment> appointments;
    private Random randomGenerator;

    public ClinicSchedule()
    {
        appointments = new ArrayList<>();
        randomGenerator = new Random(42);
    }

    public void addAppointment(Appointment appointment)
    {
        appointments.add(appointment);
    }

    public int getCount()
    {
        return appointments.size();
    }

    public void printPatientAt(int index)
    {
        if(index < 0 || index >= appointments.size()) {
            System.out.println("Invalid index");
            return;
        }

        System.out.println(appointments.get(index).getPatientName());
    }

    public boolean cancel(int index)
    {
        if(index < 0 || index >= appointments.size()) {
            return false;
        }

        if(appointments.get(index).hasCheckedIn()) {
            return false;
        }

        appointments.remove(index);
        return true;
    }

    public void printWaitingPatients()
    {
        boolean found = false;

        for(Appointment appointment : appointments) {
            if(!appointment.hasCheckedIn()) {
                System.out.println(appointment.getPatientName());
                found = true;
            }
        }

        if(!found) {
            System.out.println("No waiting patients");
        }
    }

    public int findPatientIndex(String name)
    {
        int index = 0;
        boolean found = false;

        while(index < appointments.size() && !found) {
            Appointment appointment = appointments.get(index);
            if(appointment.getPatientName().equals(name)) {
                found = true;
            }
            else {
                index++;
            }
        }

        if(found) {
            return index;
        }
        return -1;
    }

    public void printAllPatients()
    {
        appointments.forEach(appointment -> System.out.println(appointment.getPatientName()));
    }

    public void checkInAll()
    {
        appointments.forEach(Appointment::checkIn);
    }

    public int removeCheckedIn()
    {
        int before = appointments.size();
        appointments.removeIf(appointment -> appointment.hasCheckedIn());
        return before - appointments.size();
    }

    public boolean cancelPatient(String name)
    {
        return appointments.removeIf(appointment -> appointment.getPatientName().equals(name)
            && !appointment.hasCheckedIn());
    }

    public long countWaiting()
    {
        return appointments.stream()
                           .filter(appointment -> !appointment.hasCheckedIn())
                           .count();
    }

    public void printWaitingNames()
    {
        appointments.stream()
                    .filter(appointment -> !appointment.hasCheckedIn())
                    .map(appointment -> appointment.getPatientName())
                    .forEach(name -> System.out.println(name));
    }

    public int totalWaitingMinutes()
    {
        return appointments.stream()
                           .filter(appointment -> !appointment.hasCheckedIn())
                           .map(appointment -> appointment.getMinutes())
                           .reduce(0, (total, minutes) -> total + minutes);
    }

    /**
     * Find the first patient whose name matches after cleaning both names.
     * Leading and trailing spaces and differences in case are ignored.
     * @param name The name to search for; must not be null.
     * @return The first matching index, or -1 if no name matches.
     */
    public int findPatientIndexIgnoringCase(String name)
    {
        String cleanedName = name.trim().toLowerCase();
        int index = 0;

        while(index < appointments.size()) {
            String storedName = appointments.get(index).getPatientName();
            if(storedName.trim().toLowerCase().equals(cleanedName)) {
                return index;
            }
            index++;
        }
        return -1;
    }

    /**
     * Choose a patient name from all current appointments at random.
     * Checked-in appointments are included.
     * @return A stored patient name, or null if the schedule is empty.
     */
    public String randomPatientName()
    {
        if(appointments.isEmpty()) {
            return null;
        }
        int index = randomGenerator.nextInt(appointments.size());
        return appointments.get(index).getPatientName();
    }
}

Appointment.java 
public class Appointment
{
    /** The default duration used by demonstrations. */
    public static final int DEFAULT_MINUTES = 15;
    private static int appointmentsCreated = 0;

    private String patientName;
    private boolean checkedIn;
    private final int minutes;

    public Appointment(String patientName, int minutes)
    {
        this.patientName = patientName;
        this.minutes = minutes;
        checkedIn = false;
        appointmentsCreated++;
    }

    public String getPatientName()
    {
        return patientName;
    }

    public boolean hasCheckedIn()
    {
        return checkedIn;
    }

    public void checkIn()
    {
        checkedIn = true;
    }

    public int getMinutes()
    {
        return minutes;
    }

    /**
     * Report how many appointments have been constructed in this JVM.
     * Cancellation does not reduce the count.
     * @return The lifetime number of appointments created.
     */
    public static int numberOfAppointmentsCreated()
    {
        return appointmentsCreated;
    }
}
ClinicSchedule.java 
import java.util.ArrayList;
import java.util.HashMap;
import java.util.HashSet;
import java.util.Random;

public class ClinicSchedule
{
    private ArrayList<Appointment> appointments;
    private Random randomGenerator;

    public ClinicSchedule()
    {
        appointments = new ArrayList<>();
        randomGenerator = new Random(42);
    }

    public void addAppointment(Appointment appointment)
    {
        appointments.add(appointment);
    }

    public int getCount()
    {
        return appointments.size();
    }

    public void printPatientAt(int index)
    {
        if(index < 0 || index >= appointments.size()) {
            System.out.println("Invalid index");
            return;
        }

        System.out.println(appointments.get(index).getPatientName());
    }

    public boolean cancel(int index)
    {
        if(index < 0 || index >= appointments.size()) {
            return false;
        }

        if(appointments.get(index).hasCheckedIn()) {
            return false;
        }

        appointments.remove(index);
        return true;
    }

    public void printWaitingPatients()
    {
        boolean found = false;

        for(Appointment appointment : appointments) {
            if(!appointment.hasCheckedIn()) {
                System.out.println(appointment.getPatientName());
                found = true;
            }
        }

        if(!found) {
            System.out.println("No waiting patients");
        }
    }

    public int findPatientIndex(String name)
    {
        int index = 0;
        boolean found = false;

        while(index < appointments.size() && !found) {
            Appointment appointment = appointments.get(index);
            if(appointment.getPatientName().equals(name)) {
                found = true;
            }
            else {
                index++;
            }
        }

        if(found) {
            return index;
        }
        return -1;
    }

    public void printAllPatients()
    {
        appointments.forEach(appointment -> System.out.println(appointment.getPatientName()));
    }

    public void checkInAll()
    {
        appointments.forEach(Appointment::checkIn);
    }

    public int removeCheckedIn()
    {
        int before = appointments.size();
        appointments.removeIf(appointment -> appointment.hasCheckedIn());
        return before - appointments.size();
    }

    public boolean cancelPatient(String name)
    {
        return appointments.removeIf(appointment -> appointment.getPatientName().equals(name)
            && !appointment.hasCheckedIn());
    }

    public long countWaiting()
    {
        return appointments.stream()
                           .filter(appointment -> !appointment.hasCheckedIn())
                           .count();
    }

    public void printWaitingNames()
    {
        appointments.stream()
                    .filter(appointment -> !appointment.hasCheckedIn())
                    .map(appointment -> appointment.getPatientName())
                    .forEach(name -> System.out.println(name));
    }

    public int totalWaitingMinutes()
    {
        return appointments.stream()
                           .filter(appointment -> !appointment.hasCheckedIn())
                           .map(appointment -> appointment.getMinutes())
                           .reduce(0, (total, minutes) -> total + minutes);
    }

    /**
     * Find the first patient whose name matches after cleaning both names.
     * Leading and trailing spaces and differences in case are ignored.
     * @param name The name to search for; must not be null.
     * @return The first matching index, or -1 if no name matches.
     */
    public int findPatientIndexIgnoringCase(String name)
    {
        String cleanedName = name.trim().toLowerCase();
        int index = 0;

        while(index < appointments.size()) {
            String storedName = appointments.get(index).getPatientName();
            if(storedName.trim().toLowerCase().equals(cleanedName)) {
                return index;
            }
            index++;
        }
        return -1;
    }

    /**
     * Choose a patient name from all current appointments at random.
     * Checked-in appointments are included.
     * @return A stored patient name, or null if the schedule is empty.
     */
    public String randomPatientName()
    {
        if(appointments.isEmpty()) {
            return null;
        }
        int index = randomGenerator.nextInt(appointments.size());
        return appointments.get(index).getPatientName();
    }

    /**
     * Count appointments for each exact stored patient name.
     * Checked-in appointments are included.
     * @return A fresh count map; later schedule changes do not update it.
     */
    public HashMap<String, Integer> countAppointmentsByName()
    {
        HashMap<String, Integer> counts = new HashMap<>();
        for(Appointment appointment : appointments) {
            String name = appointment.getPatientName();
            int count = counts.getOrDefault(name, 0);
            counts.put(name, count + 1);
        }
        return counts;
    }

    /**
     * Collect the exact stored patient names without duplicates.
     * Checked-in appointments are included.
     * @return A fresh set; later schedule changes do not update it.
     */
    public HashSet<String> uniquePatientNames()
    {
        HashSet<String> names = new HashSet<>();
        for(Appointment appointment : appointments) {
            names.add(appointment.getPatientName());
        }
        return names;
    }
}
