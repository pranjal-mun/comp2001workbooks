Lecture summary

A playlist keeps an ordered list of track references. This class uses the lecture's Track, whose getArtist() returns the artist and whose printDetails() prints the artist and title. Use the code and table to review list operations, index checks, and loops before writing the clinic classes.

import java.util.ArrayList;

public class Playlist
{
    private ArrayList<Track> tracks;     // declares a reference

    public Playlist()
    {
        tracks = new ArrayList<>();     // creates an empty list
    }

    public void addTrack(Track track)
    {
        tracks.add(track);             // stores the reference, not a copy
    }

    public int size()
    {
        return tracks.size();          // no separate count field
    }

    public boolean isEmpty()
    {
        return tracks.isEmpty();
    }

    public void printTrack(int index)
    {
        if(index >= 0 && index < tracks.size()) {
            Track track = tracks.get(index);
            track.printDetails();      // the Track prints its own details
        }
        else {
            System.out.println("Invalid index");
        }
    }

    public void removeTrack(int index)
    {
        if(index >= 0 && index < tracks.size()) {
            tracks.remove(index);      // later elements shift left
        }
    }

    public void printAllTracks()
    {
        for(Track track : tracks) {     // visits each reference in order
            track.printDetails();
        }
    }

    public void printTracksByArtist(String artist)
    {
        boolean found = false;
        for(Track track : tracks) {
            if(track.getArtist().equals(artist)) {
                track.printDetails();
                found = true;          // at least one match was printed
            }
        }
        if(!found) {                   // also true for an empty list
            System.out.println("No matching tracks");
        }
    }
}
termmeaning
typed listArrayList<Track> is an ordered collection of Track references. A String cannot be added to this list.
declaration and constructionThe field declaration does not create a list; the field starts as null. new ArrayList<>() creates an empty list, and the diamond lets Java infer Track.
shared referencesAdding the same Track twice gives two list elements referring to one object. Adding a reference does not copy the object.
add, size, isEmptyadd(track) appends at the end. size() returns the current count; isEmpty() returns true when that count is zero.
valid indexindex >= 0 && index < tracks.size() checks both bounds. For size 3, valid indices are 0, 1, and 2. An empty list has no valid index.
getget(index) returns the reference at that position. An invalid index causes IndexOutOfBoundsException, so check before calling it.
removeremove(index) removes one list element after a bounds check. Removing index 1 from [a, b, c] gives [a, c]: the size is 2 and c shifts to index 1. Another reference can still reach the removed object.
for-eachfor(Track track : tracks) visits each list element in order. The body runs zero times for an empty list. This is definite iteration; the loop gives no index and should not remove elements from the list.
selection and found flagA for-each loop with if examines every element but prints only matches. Use equals for string contents. Start found at false, set it to true for a match, and test it after the loop to handle no matches.
item, collection, demoTrack stores and reports one recording's details. Playlist manages the collection. PlaylistDemo creates sample tracks and prints test results from main.

1. One Object, Then a Collection

A track keeps its values together

A playlist needs more than a title for each recording. One Track stores a title, artist, and duration. Its methods can answer questions about that recording.

public class Track
{
    private String title;
    private String artist;
    private int durationSeconds;

    public Track(String title, String artist, int durationSeconds)
    {
        this.title = title;
        this.artist = artist;
        this.durationSeconds = durationSeconds;
    }

    public String getArtist()
    {
        return artist;
    }
}

The string "John Coltrane - Blue Train - 643" contains the same facts, but a program would have to split the text to obtain the artist or duration. Separate fields give each value a type and a name.

A list holds many tracks

Fields called track1, track2, and track3 limit the playlist to three tracks. An ArrayList is an ordered collection that can be empty, grow, or shrink. It is a class in Java's java.util package.

import java.util.ArrayList;

public class Playlist
{
    private ArrayList<Track> tracks;

    public Playlist()
    {
        tracks = new ArrayList<>();
    }
}

The field declaration introduces a reference named tracks. The constructor creates the empty list. Track is the element type; the diamond <> lets Java infer that type on the right.

5. Visiting and Selecting Objects

For-each loops

for(Track track : tracks) {
    track.printDetails();
}

The loop variable track refers to each existing object in order. For an empty list, the body runs zero times. This is definite iteration: the collection determines the visits.

Selecting some elements

boolean found = false;
for(Track track : tracks) {
    if(track.getArtist().equals("Nick Drake")) {
        track.printDetails();
        found = true;
    }
}
if(!found) {
    System.out.println("No matching tracks");
}

The loop examines every track, but the if prints only matches. Use equals for string contents. The found variable records whether any match appeared, including when the list was empty.
